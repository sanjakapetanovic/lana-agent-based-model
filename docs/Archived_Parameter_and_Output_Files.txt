================================================================================
SEED LISTS
================================================================================

Main experiments (E1, E2, E3-S1, E3-S2, E2b): Seeds 1–50
Sensitivity experiments (E4-nominal, E4-* sweeps): Seeds 1–20
Factorial experiment (E5): Seeds 1–20 × 16 factor combinations
Robustness experiments (E6a, E6b-S1, E6b-S2): Seeds 1–20
Calibration sweep (E1b): Seeds 1–20 × 6 STIM-AMP levels
Verification experiments (E0a–E0e): Variable per test, see above

All seeds are set via the SEED parameter in BehaviorSpace.
NetLogo's random-seed command is called with this value in the setup procedure.

================================================================================
OUTPUT FILE MANIFEST
================================================================================

The data/ directory contains the raw BehaviorSpace spreadsheet-format CSV
output for each experiment. File naming follows the convention:
  LANA_v3.1_COMPLETE (1) <experiment-name>-spreadsheet.csv
or:
  LANA_v3_1_COMPLETE__2__ <experiment-name>-spreadsheet.csv

Each CSV file contains:
  - Header rows with NetLogo version, model file, experiment name, date
  - World dimensions (min/max pxcor/pycor)
  - Run number row (columns grouped by run)
  - Parameter value rows (one row per varied/fixed parameter)
  - Metric name row ([step] + metric names)
  - Data rows (final-tick values for runMetricsEveryStep=false,
    or per-tick values for runMetricsEveryStep=true)
